# ParkPass — полная концепция продукта

## 1. Общая концепция

### Название и бренд

**ParkPass** — «ваш пропуск в мир приключений».

Слоган: *«Один клик — весь парк»*.

Визуальный знак: стилизованный билет-пропуск с силуэтом американских горок, градиент от `#6366F1` (индиго) к `#F59E0B` (янтарь).

### Миссия и ценность

**Миссия:** сделать планирование поездки в тематический парк таким же простым, как бронирование отеля — без десятка вкладок, разных валют и непонятных тарифов.

**Ценность для пользователя:**

| Ценность | Описание |
|----------|----------|
| Экономия времени | Все парки, цены и отзывы в одном интерфейсе |
| Прозрачность | Итоговая цена сразу, без скрытых сборов |
| Персонализация | Рекомендации под возраст, интересы и бюджет |
| Надёжность | Подтверждение брони, напоминания, поддержка 24/7 (чат-бот + FAQ) |
| Выгода | Клубная система уровней, кэшбэк, эксклюзивные акции |

### Целевая аудитория

**Сегмент A — семьи (28–45 лет)**  
- Планируют отпуск с детьми 4–14 лет  
- Боли: сложно сравнить тарифы «взрослый/ребёнок», страх переплатить, непонятные правила отмены  
- Поведение: ищут отзывы, фото, «детский» фильтр, пакеты «семья»

**Сегмент B — молодые путешественники (18–28)**  
- Поездки с друзьями, фестивали, экстремальные аттракционы  
- Боли: очереди, нет единого приложения для разных стран  
- Поведение: мобильный трафик, короткие сессии, избранное, шеринг в соцсети

**Сегмент C — туристы-премиум (35–55)**  
- Международные парки (Disney, Universal, Ferrari World)  
- Боли: языковой барьер, VIP-опции, fast pass  
- Поведение: готовы платить за Premium-подписку и приоритетную поддержку

### Основные сценарии (User Flow)

```
[Главная] → Поиск (город/дата/гости) → [Каталог] → Фильтры → [Парк]
    → Выбор билета → [Аттракционы] → [Checkout] → Оплата → Подтверждение
    → [ЛК] → История / QR-билет

Параллельно: Регистрация → Избранное → Отзыв после визита → Повышение уровня клуба
```

**Сценарий 1 — «Быстрое бронирование»** (3–5 мин): поиск → карточка парка → дата → оплата.  
**Сценарий 2 — «Планирование отпуска»** (20+ мин): сравнение парков, избранное, виртуальный тур, отзывы.  
**Сценарий 3 — «Повторное бронирование»**: ЛК → «Забронировать снова» → скидка лояльности.  
**Сценарий 4 — «Админ партнёра»**: добавление парка, тарифов, акций.

## 3. UX/UI дизайн

### Общий стиль платформы

**Базовый стиль:** Dark UI + Glassmorphism + мягкий неон-акцент.

- Фон: `#0F172A` (slate-900)
- Поверхности: `rgba(255,255,255,0.06)` + `backdrop-blur-xl`
- Акцент: градиент `#6366F1` → `#8B5CF6`
- Успех: `#10B981`, предупреждение: `#F59E0B`, ошибка: `#EF4444`

### Типографика

| Роль | Шрифт | Размер |
|------|-------|--------|
| Display | **Clash Display** / Satoshi | 48–72px |
| Заголовки | **Inter** SemiBold | 24–36px |
| Текст | **Inter** Regular | 14–16px |
| Цены | **Tabular nums**, Bold | 20–28px |

### Анимации и micro-interactions

- Hover карточек: `scale(1.02)` + тень + свечение border
- Переходы страниц: shared element transition (Framer Motion)
- Skeleton loaders при загрузке каталога
- Кнопка «Забронировать»: пульсация при первом визите (once)
- Scroll-triggered появление блоков (fade-up)
- Число очереди: animated counter

### Эффект «вау»

- **Живые фоны:** WebM-видео в Hero (lazy, muted)
- **Параллакс** слоёв на странице парка
- **3D-карта** территории (Three.js / упрощённая SVG)
- **Particles** на главной (лёгкие, 60fps cap)
- **Звук атмосферы** (опционально, mute по умолчанию)

### Уникальный стиль каждого парка

| Парк | Палитра | Типографика | Эффекты |
|------|---------|-------------|---------|
| **Disney-style** «Magic Kingdom EU» | Розово-золотой, звёзды | Сказочный serif заголовок | Confetti, волшебные частицы |
| **Ferrari World** | `#DC0000`, чёрный, carbon texture | Bold condensed | Speed lines, rev-counter UI |
| **Aquapark Blue** | Cyan, бирюза | Rounded, «волна» | Water ripple shader |
| **Halloween Park** | Оранжевый, фиолетовый | Creepy display | Туман, flicker |

Реализация: поле `theme_config` JSON в БД → CSS variables на клиенте.

## 4. Функционал (подробно)

### Пользователь

| Функция | Описание |
|---------|----------|
| Поиск | По городу, стране, названию; автодополнение |
| Фильтрация | Цена, рейтинг, тип, возраст детей, Fast Pass |
| Просмотр аттракционов | Карточки, карта, очереди |
| Выбор даты | Календарь с ценами по дням (динамическое ценообразование) |
| Бронирование | Корзина, несколько типов билетов |
| Оплата | Имитация Stripe-like UI, статусы success/fail |
| Избранное | Синхронизация с аккаунтом |
| Клубная система | 4 уровня, баллы за бронирования и отзывы |

**Уровни клуба ParkPass:**

| Уровень | Баллы | Бонусы |
|---------|-------|--------|
| Bronze | 0 | Базовый кэшбэк 2% |
| Silver | 500 | 5% кэшбэк, приоритет поддержки |
| Gold | 2000 | 8%, ранний доступ к акциям |
| Platinum | 5000 | 12%, бесплатный Fast Pass раз в год |

### Система

- **Рекомендации:** collaborative filtering + теги интересов
- **Рейтинг:** 1–5 звёзд, модерация, ответ парка
- **Уведомления:** email + in-app (бронь, акции, очередь)

### Админ

- CRUD парков/аттракционов/тарифов
- Управление квотами билетов
- Роли: superadmin, park_manager, support
- Аналитика (графики Recharts)

## 5. Почему не официальные сайты парков

| Проблема официальных сайтов | Решение ParkPass |
|----------------------------|------------------|
| У каждого парка свой UI, язык, валюта | Единый интерфейс и checkout |
| Сложно сравнить цены | Сравнение до 3 парков side-by-side |
| Нет кросс-парковых бонусов | Клубная система и кэшбэк |
| Нет агрегированных отзывов | Единый рейтинг и фото туристов |
| Нет персонализации | AI-маршрут на день по интересам |
| Разрозненная информация об очередях | Единый виджет ожидания (где доступно) |

**Конкурентное преимущество:** ParkPass — это «Booking.com для парков»: агрегатор, а не замена парка, а **удобный слой** между туристом и поставщиком.

## 10. Уникальные фишки (WOW)

1. **AI-маршрут на день** — ввод: возраст детей, любимые аттракционы → готовый план с учётом очередей.
