# ParkPass — краткое резюме для дипломной защиты

## Проблема
Туристы тратят часы на поиск билетов в разрозненных официальных сайтах парков без единого сравнения и бонусов.

## Решение
**ParkPass** — B2C-агрегатор бронирования тематических парков с единым UX, клубной системой и AI-маршрутами.

## Технологии
Next.js · React · NestJS/Express · PostgreSQL · JWT · REST

## Результат
- 10+ страниц продукта (концепция)
- Схема БД (6+ таблиц)
- Рабочие примеры frontend/backend
- Модель монетизации (комиссия + Premium + B2B)

## Уникальность
AI-маршрут · Live Queue · 360° тур · Сравнение парков · Семейный режим
